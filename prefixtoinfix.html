Konversi Prefix ke Infix

Membaca Notasi Prefix Terbalik dan Mengembalikannya ke Bentuk Infix

Konsep Konversi

Prinsip: Ekspresi prefix dibaca secara terbalik (dari kanan ke kiri). Berbeda dengan konversi infix, dalam proses ini Stack digunakan untuk menyimpan string sub-ekspresi yang digabungkan secara bertahap.

Langkah-langkah Algoritma

Langkah 1

Mulai membaca ekspresi dari bagian paling kanan menuju ke kiri karakter demi karakter.

Langkah 2

Jika karakter adalah Operand, masukkan (push) string tersebut ke dalam stack.

Langkah 3

Jika karakter adalah Operator, ambil (pop) dua elemen teratas stack sebagai operand_A dan operand_B.

Langkah 4

Gabungkan: (operand_A operator operand_B), lalu push kembali hasilnya ke stack.

Simulasi Proses

Contoh jalannya logika untuk ekspresi prefix: + A * B C

Input Prefix: + A * B C
1. Baca C: Stack = ['C']
2. Baca B: Stack = ['C', 'B']
3. Baca *: Pop B, Pop C. Push (B * C). Stack = ['(B * C)']
4. Baca A: Stack = ['(B * C)', 'A']
5. Baca +: Pop A, Pop (B*C). Push (A + (B * C)).
Hasil Infix: (A + (B * C))

Implementasi Program (Python)

prefix_to_infix.py Python 3 
def is_operator(char):
    return char in ['+', '-', '*', '/', '^']

def prefix_to_infix(prefix):
    stack = []
    
    # Membaca dari kanan ke kiri
    for char in reversed(prefix.split() if ' ' in prefix else prefix):
        if not is_operator(char):
            # Jika operand, push ke stack
            stack.append(char)
        else:
            # Jika operator, pop 2 elemen
            op1 = stack.pop()
            op2 = stack.pop()
            
            # Gabungkan dalam format infix: (op1 operator op2)
            new_expr = f"({op1} {char} {op2})"
            stack.append(new_expr)
            
    return stack[0]

# Uji Coba
prefix_expr = "+ A * B C"
print("Infix :", prefix_to_infix(prefix_expr))

Rangkuman Materi

  • Arah Baca: Menggunakan iterasi terbalik (Reversed / Right-to-Left).
  • Stack String: Stack tidak menyimpan operator, melainkan potongan string ekspresi infix yang terus berkembang.
  • Urutan Pop: Operand pertama yang di-pop menjadi sisi kiri operator, dan yang kedua menjadi sisi kanan.
