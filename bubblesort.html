Bubble Sort

Algoritma Pengurutan Data Berbasis Pertukaran Elemen Berturut-turut

Konsep Pengurutan

Bubble Sort adalah algoritma pengurutan sederhana yang bekerja dengan cara berulang kali menelusuri daftar, membandingkan elemen yang bersebelahan, dan menukarnya jika urutannya salah.

Analogi Gelembung:

Elemen dengan nilai terbesar akan secara bertahap "mengapung" ke posisi akhir (kanan) array pada setiap iterasi, mirip dengan gelembung udara yang naik ke permukaan air.

Langkah-langkah Algoritma

Langkah 1

Bandingkan elemen pertama dengan elemen kedua.

Langkah 2

Jika elemen kiri lebih besar dari elemen kanan, lakukan pertukaran (swap).

Langkah 3

Pindah ke pasangan elemen berikutnya dan ulangi proses hingga akhir daftar.

Langkah 4

Ulangi seluruh proses untuk semua elemen hingga tidak ada lagi pertukaran yang terjadi.

Implementasi Program (Python)

bubble_sort.py Python 3 
def bubbleSort(lst):
    # Loop sebanyak panjang elemen (jumlah putaran)
    for k in range(1, len(lst)):
        # Loop untuk membandingkan elemen yang bersebelahan
        for i in range(0, len(lst)-1):
            if lst[i] > lst[i+1]:
                # Tukar posisinya di Python tanpa temp variable
                lst[i], lst[i+1] = lst[i+1], lst[i]
    return lst

# Uji Coba Program
data = [5, 0, 1, 10, 7, 2, 5, 4, 6, 9]
print("Sebelum:", data)
print("Sesudah:", bubbleSort(data))
Hasil Output:

Sebelum: [5, 0, 1, 10, 7, 2, 5, 4, 6, 9]
Sesudah: [0, 1, 2, 4, 5, 5, 6, 7, 9, 10]

Rangkuman Materi

  • Prinsip: Membandingkan pasangan elemen yang bersebelahan secara terus-menerus.
  • Kelebihan: Sangat mudah dipahami dan diimplementasikan untuk pemula.
  • Kekurangan: Kurang efisien untuk data dalam jumlah besar dengan kompleksitas waktu O(n²).
  • Python Tip: Gunakan sintaks a, b = b, a untuk menukar nilai variabel dengan ringkas.
