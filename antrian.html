Queue (Antrian)

Konsep Dasar Antrian (Queue) dan Prinsip FIFO (First In First Out)

Pengertian Queue

Queue adalah kumpulan item yang terurut di mana penambahan item baru terjadi di satu ujung yang disebut "rear" (belakang), dan penghapusan item yang sudah ada terjadi di ujung lainnya yang disebut "front" (depan).

Prinsip Utama: FIFO (First In First Out)

Prinsip ini juga dikenal sebagai "first-come first-served". Mirip dengan antrian nyata, elemen yang pertama masuk akan menjadi elemen yang pertama kali keluar dan diproses.

Operasi Dasar

enqueue(item)

Menambahkan data baru ke bagian belakang (rear) antrian.

dequeue()

Menghapus dan mengambil data dari bagian depan (front) antrian.

isEmpty()

Memeriksa apakah tumpukan dalam keadaan kosong (mengembalikan boolean).

size()

Mengembalikan jumlah elemen yang ada di dalam antrian.

Ilustrasi Cara Kerja

Visualisasi bagaimana data masuk melalui ujung belakang dan keluar melalui ujung depan antrian.

Implementasi Program (Python)

Menggunakan List Python untuk mensimulasikan tumpukan dengan metode insert untuk enqueue dan pop untuk dequeue.

queue_implementation.py Python 3 
class Queue:
    def __init__(self):
        self.items = []
        
    def isEmpty(self):
        return self.items == []
        
    def enqueue(self, item):
        # Insert di indeks 0 sebagai 'rear'
        self.items.insert(0, item) 
        print(f"Enqueue: {item}")
        
    def dequeue(self):
        # Pop dari ujung list sebagai 'front'
        if not self.isEmpty():
            item = self.items.pop()
            print(f"Dequeue: {item}")
            return item
        return "Queue Kosong"
        
    def size(self):
        return len(self.items)

# --- Uji Coba ---
q = Queue()
q.enqueue(4)
q.enqueue('dog')
q.enqueue(True)
print("Ukuran Queue:", q.size())
q.dequeue()
print("Ukuran Sekarang:", q.size())

Rangkuman Materi

  • Konsep: Struktur data linier berbasis urutan kedatangan.
  • Prinsip: Menggunakan mekanisme FIFO (First In First Out).
  • Aplikasi: Sistem antrian bank, penjadwalan CPU, dan manajemen buffer printer.
  • Operasi: Fokus pada dua ujung berbeda (Rear untuk masuk, Front untuk keluar).
