Tree (Pohon)

Konsep Dasar Pohon Berhierarki, Struktur Binary Tree, dan Representasi Data

Pengertian Tree

Tree adalah struktur data non-linear berhierarki yang terdiri dari sekumpulan elemen terhubung. Komponen pembentuk utamanya meliputi akar (root), cabang (branches), dan daun (leaves).

Perbedaan Karakteristik Utama:
• Berbeda dengan pohon alami, pohon dalam ilmu komputer direpresentasikan terbalik: posisi Root berada paling atas, sedangkan posisi Leaves berada di dasar paling bawah.
• Contoh implementasi paling umum dapat kita temukan pada penataan struktur elemen penampung dokumen web HTML (DOM Tree).

Terminologi Penting

Node

Simpul atau bagian fundamental utama yang berfungsi sebagai wadah penyimpan entitas nilai data.

Edge

Garis berarah yang mengaitkan hubungan relasi spesifik di antara dua buah simpul node.

Root

Satu-satunya node puncak tertinggi yang tidak memiliki garis masuk (no incoming edges).

Leaf Node

Simpul bagian paling ujung terminal yang sudah tidak bercabang atau tidak memiliki anak (children).

Parameter Ukuran Pohon & Kategori

Pengukuran kedalaman hierarki suatu entitas dihitung menggunakan konsep tingkatan berikut:

  • Level: Jumlah lompatan edge yang dilewati, dihitung dari simpul root utama menuju node tujuan. Secara aksioma, ketetapan level root bernilai 0.
  • Height (Tinggi Pohon): Nilai level maksimum mutlak paling dalam yang berhasil dicapai oleh simpul daun di dalam suatu struktur pohon.

Kategori Binary Tree

Pohon diklasifikasikan sebagai Binary Tree (Pohon Biner) apabila setiap simpul penampung datanya dibatasi hanya boleh memiliki maksimal dua cabang anak saja (left child dan right child).

Mekanisme Penelusuran Pohon (Tree Traversals)

Proses mengunjungi seluruh node pohon biner secara terstruktur terbagi menjadi tiga metode rekursif utama:

  1. Preorder: Kunjungi simpul root terlebih dahulu, lalu telusuri cabang kiri, kemudian cabang kanan.
  2. Inorder: Telusuri cabang kiri terlebih dahulu, kunjungi simpul root, kemudian telusuri cabang kanan.
  3. Postorder: Telusuri cabang kiri, telusuri cabang kanan, kemudian baru kunjungi simpul root utama.

Implementasi Program (Python)

Mengonstruksi kelas BinaryTree menggunakan representasi referensi objek rekursif untuk anak kiri dan kanan.

binary_tree.py Python 3 
class BinaryTree:
    def __init__(self, rootObj):
        self.key = rootObj
        self.leftChild = None  # Cabang anak kiri
        self.rightChild = None # Cabang anak kanan

    def insertLeft(self, newNode):
        if self.leftChild == None:
            self.leftChild = BinaryTree(newNode) # Jika kosong, buat simpul baru
        else:
            t = BinaryTree(newNode) # Sisipkan di tengah jika sudah ada isi
            t.leftChild = self.leftChild
            self.leftChild = t

    def insertRight(self, newNode):
        if self.rightChild == None:
            self.rightChild = BinaryTree(newNode)
        else:
            t = BinaryTree(newNode)
            t.rightChild = self.rightChild
            self.rightChild = t

    def getLeftChild(self):
        return self.leftChild # Ambil objek anak kiri

    def getRightChild(self):
        return self.rightChild # Ambil objek anak kanan

    def getRootVal(self):
        return self.key # Ambil isi nilai kunci

# --- Mekanisme Penelusuran Rekursif (Traversal) ---
def preorder(tree):
    if tree != None:
        print(tree.getRootVal(), end=" ") # Kunjungi Root
        preorder(tree.getLeftChild())     # Telusuri Kiri
        preorder(tree.getRightChild())    # Telusuri Kanan

def inorder(tree):
    if tree != None:
        inorder(tree.getLeftChild())      # Telusuri Kiri
        print(tree.getRootVal(), end=" ") # Kunjungi Root
        inorder(tree.getRightChild())     # Telusuri Kanan

# --- Uji Coba Bangun Pohon ---
t = BinaryTree("A")
t.insertLeft("B")
t.insertRight("C")
print("Penelusuran Inorder:")
inorder(t)

Rangkuman Materi Tree

  • Struktur: Hierarki satu induk utama (Root) ke banyak anak (Branches/Leaves).
  • Aturan Biner: Batas muatan anak maksimal berjumlah dua (kiri dan kanan).
  • Penelusuran: Preorder (Root-Kiri-Kanan), Inorder (Kiri-Root-Kanan), dan Postorder (Kiri-Kanan-Root).
  • Manfaat Kasus: Struktur berkas OS, DOM website, berkas JSON/XML, dan Parse Tree kalkulator logika.
