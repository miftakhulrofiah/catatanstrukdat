Double Antrian (Deque)

Struktur Data Antrian Dua Arah yang Fleksibel (Front & Rear Access)

Pengertian Deque

Deque (singkatan dari Double-Ended Queue) adalah struktur data linear yang sangat fleksibel. Berbeda dengan Queue biasa yang hanya mengizinkan penambahan di belakang dan penghapusan di depan, Deque memungkinkan kedua operasi tersebut dilakukan di kedua ujungnya.

Karakteristik Utama:

Deque bisa berperilaku sebagai Stack (LIFO) atau Queue (FIFO) tergantung bagaimana cara kita memanipulasinya. Ini menjadikannya salah satu struktur data yang paling serbaguna.

Operasi Utama

addFront(item)

Menambahkan elemen baru ke ujung depan deque.

addRear(item)

Menambahkan elemen baru ke ujung belakang deque.

removeFront()

Menghapus dan mengambil elemen dari ujung depan.

removeRear()

Menghapus dan mengambil elemen dari ujung belakang.

Implementasi Program (Python)

Implementasi Deque menggunakan list Python, di mana ujung indeks 0 dianggap sebagai Rear dan ujung terakhir dianggap sebagai Front.

deque_implementation.py Python 3 
class deQueue:
    def __init__(self):
        self.items = []
        
    def isEmpty(self):
        return self.items == []
        
    def addRear(self, item):
        self.items.insert(0, item)
        print(f"Add Rear: {item}")
        
    def addFront(self, item):
        self.items.append(item)
        print(f"Add Front: {item}")
        
    def removeFront(self):
        if not self.isEmpty():
            item = self.items.pop()
            print(f"Remove Front: {item}")
            return item
        
    def removeRear(self):
        if not self.isEmpty():
            item = self.items.pop(0)
            print(f"Remove Rear: {item}")
            return item
        
    def size(self):
        return len(self.items)

# --- Uji Coba ---
dq = deQueue()
dq.addRear(4)
dq.addFront('dog')
dq.addFront('cat')
dq.removeRear()  # Menghapus '4'
print("Ukuran Sekarang:", dq.size())

Rangkuman Materi Deque

  • Hibrida: Gabungan fungsionalitas Stack (pop/push) dan Queue (enqueue/dequeue).
  • Indeks: Dalam list Python, append/pop efisien untuk Front, sedangkan insert(0)/pop(0) digunakan untuk Rear.
  • Fleksibilitas: Dapat digunakan untuk mengecek Palindrome karena akses simetris di kedua ujung.
  • Output: Memberikan kontrol penuh bagi pengembang untuk menentukan arah aliran data.
