Evaluasi Postfix

Menghitung Hasil dari Notasi Postfix Menggunakan Struktur Data Stack

Konsep Evaluasi

Prinsip: Ekspresi dibaca dari kiri ke kanan. Stack digunakan untuk menyimpan angka (operand) sementara hingga ditemukan operator yang akan memproses angka-angka tersebut.

Langkah-langkah Algoritma

Langkah 1

Baca token dari kiri ke kanan. Jika token adalah Angka, push ke dalam Stack.

Langkah 2

Jika token adalah Operator, pop dua elemen teratas dari stack (misal angka2 lalu angka1).

Langkah 3

Hitung hasil: angka1 (operator) angka2. Simpan (push) hasilnya kembali ke Stack.

Langkah 4

Ulangi hingga semua token terbaca. Hasil akhir adalah satu-satunya elemen yang tersisa di Stack.

Contoh Visual: 4 5 6 * -

1. Baca 4, 5, 6: Stack = [4, 5, 6]
2. Baca *: Pop 6, Pop 5. Hitung 5 * 6 = 30. Push 30. Stack = [4, 30]
3. Baca -: Pop 30, Pop 4. Hitung 4 - 30 = -26. Push -26. Stack = [-26]
Hasil: -26

Implementasi Program (Python)

postfix_evaluation.py Python 3 
def evaluasi_postfix(ekspresi):
    stack = []
    tokens = ekspresi.split()

    for token in tokens:
        # Cek jika token adalah angka (mendukung angka negatif)
        if token.isdigit() or (token.startswith('-') and token[1:].isdigit()):
            stack.append(int(token))
        else:
            # Ambil dua angka terakhir dari stack
            angka2 = stack.pop()
            angka1 = stack.pop()

            if token == '+': hasil = angka1 + angka2
            elif token == '-': hasil = angka1 - angka2
            elif token == '*': hasil = angka1 * angka2
            elif token == '/': hasil = angka1 / angka2
            
            # Masukkan hasil kembali ke stack
            stack.append(hasil)

    return stack.pop()

# Uji Coba
exp = "4 5 6 * -"
print(f"Hasil dari '{exp}' adalah: {evaluasi_postfix(exp)}")

Rangkuman Materi

  • Stack Angka: Berbeda dengan konversi, di sini stack menyimpan hasil perhitungan numerik.
  • Urutan Operand: Penting untuk diingat bahwa operand pertama yang di-pop adalah sisi kanan operator (angka2).
  • Efisiensi: Komputer mengevaluasi postfix lebih cepat karena tidak perlu memproses prioritas atau tanda kurung secara rekursif.
