Selection Sort

Algoritma pengurutan berdasarkan pencarian nilai minimum secara iteratif

Konsep Selection Sort

Selection Sort adalah algoritma pengurutan yang bekerja dengan cara mencari nilai minimum (terkecil) di sisa array yang belum terurut, lalu memindahkannya ke posisi paling awal secara bertahap.

Prinsip Kerja:

1. Cari nilai terkecil dari indeks yang belum urut.
2. Tukar posisi nilai tersebut dengan elemen di batas awal bagian belum urut.
3. Geser batas awal tersebut satu posisi ke kanan.

Langkah-langkah Algoritma

Langkah 1

Asumsikan elemen pertama sebagai nilai minimum sementara (min_idx).

Langkah 2

Bandingkan elemen tersebut dengan elemen sisa di sebelah kanannya untuk mencari nilai yang lebih kecil.

Langkah 3

Jika ditemukan nilai yang lebih kecil, perbarui posisi min_idx.

Langkah 4

Setelah selesai menelusuri satu putaran, tukar elemen pada min_idx dengan elemen di posisi iterasi saat ini.

Implementasi Program (Python)

selection_sort.py Python 3 
def selectionSort(lst):
    for i in range(0, len(lst)-1):
        min_idx = i
        # Cari nilai terkecil di sisa list (yang belum diurutkan)
        for j in range(i+1, len(lst)):
            if lst[j] < lst[min_idx]:
                min_idx = j
                
        # Tukar posisi awal (i) dengan posisi nilai terkecil (min_idx)
        lst[i], lst[min_idx] = lst[min_idx], lst[i]
    return lst

# Uji Coba
data = [4, 7, 1, 9, 3, 10, 6]
print("Sebelum:", data)
print("Sesudah:", selectionSort(data))
Hasil Output:

Sebelum: [4, 7, 1, 9, 3, 10, 6]
Sesudah: [1, 3, 4, 6, 7, 9, 10]

Rangkuman Materi

  • Mekanisme: Secara iteratif "memilih" elemen terkecil dan meletakkannya di posisi yang tepat.
  • Kelebihan: Meminimalisir jumlah pertukaran data (swap) dibandingkan Bubble Sort.
  • Kompleksitas: Tetap O(n²) karena adanya perulangan bersarang untuk mencari nilai minimum.
